## Minnesota State Housing Tax Credit (SHTC) Data Analysis | Habitat for Humanity Minnesota

Conducted exploratory data analysis of Minnesota’s State Housing Tax Credit program using data from 2023–2026 to examine program growth, contributor patterns, affordable housing developers, and the geographic distribution of funding. Analyzed funding trends and developed data visualizations identifying disparities between the Twin Cities metro area and Greater Minnesota. Translated findings into a comprehensive 10-page report with policy recommendations and a one-page legislative brief advocating for program extension and more equitable geographic funding allocation.

Key deliverables: Comprehensive data analysis report, legislative one-pager, funding visualizations, and an Excel PivotTable for exploring program data by year, housing type, county, city, and region.
